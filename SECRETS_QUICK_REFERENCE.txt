  STREAMLIT CLOUD SECRETS - QUICK SETUP GUIDE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Open Your secrets.toml File
  Location: .streamlit/secrets.toml
  Action: Copy ALL content from this file

STEP 2: Go to Streamlit Cloud
  1. Navigate to: https://share.streamlit.io
  2. Find your app
  3. Click "Edit secrets" or go to Settings → Secrets
  4. Paste the entire secrets.toml content

STEP 3: Check Required Fields
  The following MUST be filled (check they're not empty):

  ✓ GEMINI_API_KEY = "AIzaSy..."
  ✓ GOOGLE_API_KEY = "AIzaSy..."
  ✓ GAS_WEB_APP_URL = "https://script.google.com/macros/s/..."
  ✓ GOOGLE_SHARED_DRIVE_ID = "0AHYuYj..."
  ✓ FOLDER_DRIVE_ID = "16X-8eTP..."
  ✓ RESEARCH_FILES_FOLDER_ID = "1PyOr7o..."
  ✓ GDRIVE_CREDENTIALS_JSON = { entire JSON from service account }

STEP 4: Save & Wait
  1. Click "Save" button
  2. Wait 1-2 minutes for changes to propagate
  3. Restart your app (click "Rerun")

STEP 5: Test
  1. Upload a PDF
  2. Select a template
  3. Generate a deck
  4. Check Generation History for results

═══════════════════════════════════════════════════════════════════════════════
  WHAT TO DO IF SOMETHING FAILS
═══════════════════════════════════════════════════════════════════════════════

Error: "Required environment variable 'X' is not set"
→ Check that the variable is in your secrets (not empty)
→ Wait another minute and refresh
→ Restart the app

Error: "Invalid JSON in GDRIVE_CREDENTIALS_JSON"
→ Open secrets.toml and check the JSON formatting
→ Make sure it's valid JSON (use jsonlint.com to validate)
→ Check for trailing commas or unclosed brackets

Error: "The caller does not have permission"
→ Your service account needs access to the shared drive
→ Share the drive with: ppt-generator@battle-card-1.iam.gserviceaccount.com

═══════════════════════════════════════════════════════════════════════════════
  GETTING YOUR SERVICE ACCOUNT JSON (if needed)
═══════════════════════════════════════════════════════════════════════════════

1. Go to: Google Cloud Console → Service Accounts
2. Find "ppt-generator" or your service account
3. Click it
4. Go to "Keys" tab
5. Click "Add Key" → "Create new key" → "JSON"
6. A JSON file downloads - open it
7. Copy EVERYTHING (all the text)
8. Paste into GDRIVE_CREDENTIALS_JSON field

The JSON starts with:  {
  "type": "service_account",
  "project_id": "...",

And ends with:  }
