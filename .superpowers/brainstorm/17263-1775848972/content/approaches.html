A — Progressive Disclosure

Single screen. Regular users describe + upload and go. "Advanced" toggle reveals template picker, variable fields, and slide toggles. Always feels simple unless you need control.

Pros

  • Lowest friction for new users
  • One screen, no wizard steps

Cons

  • Power features feel hidden
  • Advanced panel can get crowded

B — Two-Path Wizard

Users pick their mode upfront: Quick Generate (AI-driven) or Custom Build (full control). Each path is a separate, focused flow. Makes the two user types explicit.

Pros

  • Each path is clean & uncluttered
  • Clear mental model

Cons

  • Extra click for everyone
  • Power users always go to same path

C — Template-First

Template selection is always the first step. "Suggest Template" button is right there alongside manual picks. Selecting a template reveals its variables and slide list. Natural language input lives in the Suggest flow.

Pros

  • Variables & slides are template-specific — logical order
  • Suggest button is always visible, not buried

Cons

  • Regular users still see template names even if AI picks
  • More upfront UI complexity

My recommendation: C — Template-First, because variables and skippable slides are template-specific — they only make sense after a template is selected. The "Suggest Template" button is front-and-center, not hidden. Regular users click Suggest, describe their goal, done. Power users pick manually.
